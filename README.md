# Pixel Positions

Pixel Positions is a Laravel-based web application created as part of my learning journey using the [30 Days to Learn Laravel 11](https://laracasts.com/series/30-days-to-learn-laravel-11) series on [Laracasts](https://laracasts.com).

This project served as a hands-on exercise to understand the core features of the Laravel framework, including routing, controllers, models, Eloquent ORM, migrations, validation, and more.

---

## 🚀 About the Project

- **Framework**: Laravel 11
- **Purpose**: Learning exercise while following Laracasts tutorials
- **Series**: [30 Days to Learn Laravel 11](https://laracasts.com/series/30-days-to-learn-laravel-11)

---

## 🛠 Features

- Routing and controllers
- Eloquent ORM for database interaction
- Blade templating engine
- Request validation
- Database migrations and seeders
- Authentication scaffolding (optional)
